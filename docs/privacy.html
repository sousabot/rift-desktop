Privacy Policy

Last updated: 29 August 2026

This policy covers the public Rift.lol website (stats, ladders, scouting, esports, and related pages) and the Windows desktop app.

What we collect

The website is built around looking up League of Legends players. Anyone can search a Riot ID, open a dashboard, browse a ladder, open a scouting row, or view an esports profile. Those requests use public Riot Games API data and public community sources for the name or roster you asked for. Searching someone does not link their account to you and does not require their password.

If you link your own Riot ID (game name, tag, and region) on the website or in the app, we use it the same way: to fetch summoner profile, ranked record, match history, timelines, live-game participants, and champion mastery.

Optional feedback (title, details, contact) may be sent to our Discord webhook so we can fix bugs.

Your browser may store a linked Riot ID, UI preferences (such as a country filter), and a random device id for checkout in local storage. We do not use tracking cookies for ads.

What we do not collect

We do not ask for Riot passwords. We do not sell player data. We do not run ads. We do not keep a private dossier of every summoner on League — we request data when you (or another visitor) ask for it, and we cache some responses for a short time so the site stays fast.

Where data lives

On the website, League data is requested through our HTTPS API (hosted on Render). That server holds the Riot key, rate-limits requests, and only forwards calls to official Riot Games API hosts and the public data sources the pages already show (for example community ladders used for scouting and esports). Short-lived caches may sit on that server so repeated views of the same ladder or profile are not refetched every time.

On the Windows app, linked-account settings and short-lived caches stay on your PC. The app does not embed a Riot API key.

We do not use match history as a marketing list. Premium checkout, if you use it, is handled by our payment provider; we receive the minimum we need to unlock Premium (such as a session or device id).

Third parties

League data comes from Riot Games. Champion, item, rank, and profile images may load from Riot’s Data Dragon / Community Dragon CDNs or similar public CDNs. Esports and scouting pages may use public community APIs. Feedback may be delivered via Discord. Payments go through our checkout provider. Those services have their own policies.

Contact

Questions about this policy: open an issue on the GitHub repository, or use Report feedback / bugs in the Windows app if you have it installed.
